## Estructura de cada entrada

Cada archivo `YYYY-MM_autor_titulo-corto.md` contiene:

- **Metadatos**: título, autores, año, fuente, tags, relevancia
- **Tesis central**: argumento principal del paper
- **Conexión con framework**: vínculo con EPT, EGT, multilevel intentionality, JurisRank, IusSpace u otros marcos del programa
- **Técnica implementable**: si aplica (AI/agentes/skills)
- **Citas clave**: pasajes relevantes para citación
- **Next actions**: qué hacer con este paper
